

\# Team 7 - Causal Study of Test Smells



\## Project Overview



This project investigates the relationship between test smells and software testing outcomes.



\## Project Structure



\- `src/`: Source code

\- `data/`: Collected datasets

\- `experiments/`: Experiment scripts

\- `results/`: Experimental outputs

\- `analysis/`: Data analysis

\- `docs/`: Project documentation

\- `tests/`: Code tests



\## Environment



\- Python 3.12.6

\- Git



\## Setup



Create and activate a Python virtual environment, then install the required dependencies when they are defined.



\## Status



Initial project setup completed. Research methods, tools, and datasets are yet to be confirmed.
