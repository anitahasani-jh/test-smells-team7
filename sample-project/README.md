# Sample Java Project

This small Maven/JUnit project is included only to smoke-test the developer pipeline.

## Contents

- `src/main/java/org/example/App.java`: sample methods `add` and `multiply`.
- `src/test/java/org/example/AppTest.java`: basic JUnit 4 tests.
- `pom.xml`: Maven configuration.

## Run tests

From this directory, run:

```bash
mvn test
```

## Important limitation

This is a tiny example project, not a research dataset. Its tests and history must not be treated as evidence for causal claims or general conclusions about Test Smells. The actual approved detector and study repositories still need to be selected by the team/instructor.
